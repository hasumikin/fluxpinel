# The hand-written methods that a generated wrapper answers too, as the
# last make regress found them (docs/design.md, section 3.2.2). A line
# names the method, then a tab and a reason, or no reason.
#
# A line with no reason is work to do: remove the hand-written method,
# run make regress, remove the line. A line with a reason keeps the
# method: the reason names what the row lacks for the walker, and goes
# to spinel as an issue. tools/builtin_census.rb fails on a shadow that
# is not here.
ANY_ARRAY/poly_array#dup/0	the row answers a plain Array; an instance of a subclass of Array keeps its class
ANY_HASH/poly_poly_hash#dup/0	the row answers a plain Hash; an instance of a subclass of Hash keeps its class
ANY_HASH/poly_poly_hash#to_h/0	the row answers the receiver; an instance of a subclass of Hash answers a plain Hash
addrinfo/addrinfo#inspect/0	fx_core of Fluxpinel answers inspect of every receiver before the table; the row never runs
addrinfo/addrinfo#to_sockaddr/0	the row answers a text String; CRuby answers a binary String
complex/complex#==/1	the row answers false for an object of the program; CRuby asks the == of the object
complex/complex#fdiv/1	tools/bop_gen.c skips the row with an Integer or Float argument ($e of no single kind); the row that fits raises TypeError
float_range/float_range#first/0	the row raises TypeError (can't iterate from Float); CRuby answers the begin
io/io#flock/1	the row waits inside flock(2), which stops the one OS thread of a standalone program; the hand-written call asks with LOCK_NB and sleeps
matchdata/matchdata#string/0	the row answers a new String; CRuby answers the frozen subject itself
str_range/str_range#%/1	fx_core of Fluxpinel answers % of every receiver before the table; the row never runs
str_range/str_range#begin/0	the row answers a String for an end of a Range of Symbols; CRuby answers the Symbol
str_range/str_range#end/0	the row answers a String for an end of a Range of Symbols; CRuby answers the Symbol
str_range/str_range#first/0	the row answers a String for an end of a Range of Symbols; CRuby answers the Symbol
str_range/str_range#last/0	the row answers a String for an end of a Range of Symbols; CRuby answers the Symbol
string/string#concat/0	the row answers a new String; CRuby answers the receiver itself
string/string#end_with?/1	bop_rows[] has no String#start_with? with one argument; the pair stays together
string/string#gsub/2	the row leaves $~ as it is; CRuby sets it for a String pattern too
string/string#prepend/0	the row answers a new String; CRuby answers the receiver itself
string/string#sub/2	the row leaves $~ as it is; CRuby sets it for a String pattern too
string/string#to_s/0	the row answers the receiver; an instance of a subclass of String answers a plain String
string/string#to_str/0	the row answers a new String; CRuby answers the receiver itself
symbol/symbol#[]/2	the row reads both arguments as Integers; CRuby takes a Regexp and a group too
symbol/symbol#start_with?/1	the String argument of the row takes any boxed value (TypeError for a Regexp); CRuby matches a Regexp
